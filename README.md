# きょうりゅう だーれだ？

かわいい恐竜や古生物のシルエットを見て、2つの名前から正解を選ぶブラウザゲームです。3歳程度の幼児から大人まで遊べます。全5問で、12種類の中からランダムに登場します。

## 起動方法

`index.html` をダブルクリックしてブラウザで開くだけで遊べます。Webサーバー、npm、ビルド処理は不要です。音声読み上げには対応ブラウザの SpeechSynthesis API、効果音には Web Audio API を使用します。音声機能が使えない環境でもゲームは進行します。

## ファイル構成

- `index.html` — ページ本体
- `style.css` — レイアウト、配色、レスポンシブ表示、アニメーション
- `app.js` — 恐竜データ、インラインSVG生成、出題、採点、音声、効果音
- `README.md` — この説明書

恐竜はゲーム専用に生成した高精細なローカル画像を同梱しています。外部画像・音声・フォント・ライブラリ・APIへの実行時依存はありません。

## 恐竜の追加方法

`app.js` の `dinosaurs` 配列にオブジェクトを追加します。`id`、`name`、`speak`、`type`、`description`、`color`、`svg()` を設定してください。`svg()` は共通の `svg()` 関数を使い、`viewBox="0 0 520 300"` 内に収まる図形を返します。色の付く図形には `class="color"`、目などの細部には `class="detail"` を付けると、問題中に自動でシルエット表示になります。

## GitHub Pagesへの公開方法

1. このフォルダのファイルを GitHub リポジトリへ追加してプッシュします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、公開するブランチ（通常は `main`）と `/ (root)` を指定して保存します。
4. 表示された公開URLへアクセスします。

相対パスだけを使用しているため、プロジェクトページでもそのまま動作します。

## Vercelへの公開方法

1. Vercelで **Add New → Project** を選び、このGitHubリポジトリを読み込みます。
2. Framework Preset は **Other**、Build Command は空欄、Output Directory は `.` のままデプロイします。

または Vercel CLI でこのフォルダを指定してデプロイできます。静的ファイルだけで構成されているため、追加設定は不要です。
